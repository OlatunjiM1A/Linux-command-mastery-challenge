## What I practiced
I opened a new file in vim, typed three lines of text, saved it,
reopened it, deleted the middle line, undid that deletion, then saved
and quit for good.

## What surprised me
I didn't expect vim to have such a strict separation between "typing
mode" and "command mode." Forgetting to press Esc before trying to save
meant my :w command just got typed as literal text into the file instead
of running as a command — a mistake I now understand is extremely
common for beginners.
