 
## Day 1 — File Navigation & Filesystem Mastery

1. pwd — it prints the full path of the directory I'm currently in
2. ls — it lists files and folders in the current directory
3. ls -l — it is a long listing: showing permissions, owner, group, size, and last modified date
4. ls -a — it shows all files including hidden ones (dotfiles like .bashrc)
5. ls -la — it combines long format and hidden files in one view
6. ls -lh — it is a long format but with human-readable sizes (e.g. 4.0K instead of 4096)
7. cd /var/log — it moves into /var/log using its absolute path from root
8. cd .. — it moves up one level to the parent directory
9. cd ~ — it jumps straight back to my home directory regardless of where I am
10. cd - — it jumps back to whichever directory I was just in before the last cd
