
# Day 1 — Practice Drill

## Task

I needed to navigate through the Linux filesystem using an absolute path and directory shortcuts.

The drill required me to:

1. Print my current working directory.
2. Navigate to '/var/log' using an absolute path.
3. Return to my home directory using '~'.
4. Return to '/var/log' using 'cd -'.
5. List the contents of '/var/log' using long, human-readable formatting.
   
## Commands I Ran

```bash
pwd
cd /var/log
cd ~
cd -
ls -lh
