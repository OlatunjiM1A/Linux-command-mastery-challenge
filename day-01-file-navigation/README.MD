# Day 1 — Where Am I? Basic Orientation

## Phase 1 — File Navigation & Filesystem Mastery

### Commands Covered

Today I practiced 10 Linux commands and command variations for navigating and inspecting the filesystem.

See [commands.md](commands.md) for the complete list and my explanations.

### What I Practiced

I practiced checking my current location, listing files, and navigating between directories using absolute paths, the home directory shortcut, the parent directory, and the previous-directory shortcut.

For the practice drill, I navigated to `/var/log`, returned to my home directory, returned to `/var/log` using `cd -`, and listed its contents using a long, human-readable format.

### What Surprised Me

I learned that `cd -` switches between the current directory and the previous directory rather than keeping a complete navigation history.
