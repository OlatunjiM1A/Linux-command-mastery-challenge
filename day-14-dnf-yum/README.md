## What I practiced
On an Amazon Linux/RHEL-style system, I installed a package with dnf,
confirmed it was installed using rpm -qa, then compared the workflow
step by step against the equivalent apt commands from Day 13.

## What surprised me
The workflow is nearly identical in structure to apt — update, install,
remove — just with different command names and package formats (.rpm
vs .deb). It reframed dnf/yum less as "a whole new system to learn" and
more as "the same concepts, different vocabulary."
