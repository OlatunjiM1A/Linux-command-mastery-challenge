# 30-Day Linux Command Mastery Challenge

## About the Challenge

This repository documents my journey through the 30-Day Linux Command Mastery Challenge, where I am building practical command-line fluency by learning and practicing 300 Linux commands and their derivatives over 30 days.

The challenge covers file navigation, permissions, users and groups, package management, environment configuration, text processing, process and service management, networking, Bash scripting, and SSH.

My goal is not just to memorize commands, but to understand when and why to use them through hands-on practice, daily drills, documentation, and evidence of my work.
