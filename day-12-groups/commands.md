1. `groupadd` — Create a new group
2. `groupdel` — Delete a group
3. `gpasswd -a` — Add a user to a group
4. `gpasswd -d` — Remove a user from a group
5. `getent group` — Look up group information
6. `getent passwd` — Look up user information
7. `groups` — Display a user's group memberships
8. `id -Gn` — Display group names for a user
9. `newgrp` — Start a shell using another group as the effective group
10. `cat /etc/group` — Display the system group database
