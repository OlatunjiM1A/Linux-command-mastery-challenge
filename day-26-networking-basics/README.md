## What I practiced
I identified my machine's IP address and default gateway, tested
connectivity to a public host, fetched a URL's headers only, and
listed every port currently listening on the system.

## What surprised me
I didn't realize curl -I fetches only the response headers without
downloading the full page content. It's a much faster way to check if
a site is up and what server it's running than opening it in a browser
or pulling the whole page with a plain curl.
